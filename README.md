# SQL Practice

## 📌 Overview
This repository contains personal SQL practice exercises and notes created to strengthen query writing skills. It is intended as a self-learning resource to explore different SQL concepts and improve hands-on proficiency.

## 🗂️ Contents
- **Basic Queries**: SELECT, WHERE, ORDER BY  
- **Joins**: INNER JOIN, LEFT JOIN, RIGHT JOIN  
- **Aggregations**: GROUP BY, HAVING, COUNT, SUM, AVG  
- **Subqueries**: Nested queries, correlated subqueries  
- **Performance Tuning**: Index usage, query optimization, execution plans  

## 🎯 Purpose
- Practice SQL concepts through hands-on examples  
- Build personal notes and references for continuous learning  
- Track progress and improvements over time  

## 🚀 How to Use
- Clone the repository  
- Run scripts in your preferred SQL environment (MySQL, PostgreSQL, SQL Server, etc.)  
- Review notes and examples for self-study and revision
